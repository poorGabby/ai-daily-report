# 设计趋势 - 2026-07-03

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于代理式用户体验（UX）和AI在设计工作流程中的应用。主要动态包括：1) 面向代理的UX设计原则，旨在提升数字设备中的新型用户体验；2) 代理式UX设计的核心在于人机间的信任协调；3) AI工具加速设计工作流程，提升协作与灵活性；4) AI代理工作流设计模式的分类与实例分析；5) 设计智能代理系统时需确保上下文双向流动以增强信任。最值得关注的是代理式UX设计原则和AI工具对设计工作流程的影响。
