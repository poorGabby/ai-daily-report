# 设计趋势 - 2026-07-05

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于代理型用户体验（代理UX）和AI在设计工作流程中的应用。主要动态包括探讨代理UX设计原则、光标和Manus等工具的AI集成，以及代理型UX对设计认知的影响。最值得关注的是光标、氛围编码和Manus工具的用户体验革命，以及代理式UX的7个设计原则，这些将推动人机交互向更自然、目标导向的方向发展。
