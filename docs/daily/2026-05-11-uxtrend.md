# 设计趋势 - 2026-05-11

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于AI交互模式的创新和设计师角色的转变。AI交互模式的发展让用户更易识别和互动AI功能，而设计师在AI时代转变为协调者，影响企业财务。最值得关注的是零点击界面和Cursor IDE的应用，前者强调AI时代的不确定性，后者通过集成大型语言模型提升开发效率。
