# 设计趋势 - 2026-08-02

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI与用户体验的融合，其中Agentic UX设计和AI工作流程创新尤为突出。Agentic UX设计通过人性化交互提升用户对AI的信任和理解，而AI工作流程则通过Figma社区支持，推动创意项目的高效实现。最值得关注的是Agentic UX设计，它预示着人工智能代理在用户体验设计中的重要性日益增强。

### 1. Agentic UX设计：AI代理的人性化交互

**原文标题**: [Medium](https://resolutesoftware.medium.com/3-useful-instruments-to-enable-your-agentic-ux-turn-user-intent-into-business-outcomes-fb0813bbe410)

**一句话摘要**: Agentic UX设计旨在将AI技术转化为用户可理解、信任的有效工作流程。

**能解决什么问题**: 解决AI代理在理解意图、决策、沟通不确定性和与人类协作中的挑战。

**产品应用**: 适用于需要AI自动化流程的高风险环境，如医疗、金融等领域。

**示例场景**: 在医疗诊断中，AI代理辅助医生做出决策。
