# 设计趋势 - 2026-08-11

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI与用户体验的融合。代理UX设计原则、AI工作流优化、以及AI代理的Agent Experience成为讨论热点。Figma的AI工作流程为创意项目提供新起点。2026年设计师调查显示，AI显著提升设计品质。最值得关注的是AI在提升设计质量和用户体验设计的新维度。

### 1. 面向代理的用户体验设计

**原文标题**: [UX design for agents](https://medium.com/microsoft-design/ux-design-for-agents-11336728b445)

**一句话摘要**: 探讨了设计新型数字设备用户体验的代理UX设计原则。

**能解决什么问题**: 如何确保在AI驱动的代理系统中以人为中心。

**产品应用**: 适用于任何产品开发过程，通过以用户问题为中心来设计解决方案。

**示例场景**: 使用AI代理系统辅助团队协作和问题解决。

### 2. AI工作流设计的误区：模仿人类而非优化功能

**原文标题**: [Medium](https://skooloflife.medium.com/the-biggest-mistake-in-ai-workflow-design-mimicking-human-process-instead-of-optimizing-function-628bfa37aa02)

**一句话摘要**: AI工作流设计应基于功能优化而非模仿人类行为。

**能解决什么问题**: 解决AI工作流设计中将AI视为“某人”而非“某物”的错误观念。

**产品应用**: 可以应用到实际产品中，通过直接嵌入功能而非模拟人类工作流程。

**示例场景**: 在客服系统中，直接调用AI接口处理查询而非模拟人工对话。

### 5. 2026年设计师现状：AI提升设计品质

**原文标题**: [Medium](https://medium.com/design-bootcamp/product-designers-are-not-being-replaced-they-are-being-sorted-6e2fb0492ed2)

**一句话摘要**: 91%的设计师认为AI提高了设计质量而非仅速度。

**产品应用**: 适用于产品设计，AI辅助初步设计，人类设计师完成细节和策略。

**示例场景**: 设计师使用AI生成初步界面，然后进行人工优化。
