# 设计趋势 - 2026-08-04

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势资讯汇总：智能代理用户体验设计成为焦点，强调数字设备上的新型体验；AI驱动工作流程和AI工作流设计规则被讨论，突出功能导向而非模拟人类。最值得关注的是AI辅助工作流开发的最佳实践，以及人工智能时代下的Agent UX设计，后者强调人、算法和系统间的逻辑、沟通和信任。
