# 设计趋势 - 2026-06-09

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI在工作流、创造方式、交互模式和用户体验中的应用。AI代理工作流设计模式强调其作为任务协调器的角色，而AI在设计中的应用预示着创作方式的变革，提升适应性和团队协作。最值得关注的趋势是AI交互模式的建立，它通过交互模式建立人与AI之间的信任关系，以及设计代理型用户体验指南，它从即时任务导向转变为预测用户未知需求的代理型设计。
