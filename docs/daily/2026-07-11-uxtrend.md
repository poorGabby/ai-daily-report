# 设计趋势 - 2026-07-11

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于AI在用户体验和设计工作流程中的应用。其中，代理UX设计原则的探索和Cursor IDE的自然对话式AI协作是值得关注的亮点。AI不仅改变了设计工作流程，提高了效率，还促使设计师创造更易于理解和信任的AI友好型产品。
