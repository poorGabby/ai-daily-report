# 设计趋势 - 2026-05-08

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI在用户体验中的应用。主要动态包括：1) 代理型用户体验设计指南强调理解用户目标和偏好；2) 提供7个AI工作流优化技巧；3) 探讨AI交互模式，让用户轻松识别和互动AI功能；4) 分析AI工具在产品设计师工作流程中的应用；5) 探讨AI如何辅助用户工作流程。最值得关注的是AI工作流优化技巧和AI交互模式的探索，它们将直接影响设计师的工作效率和用户的交互体验。
