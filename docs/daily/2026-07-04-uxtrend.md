# 设计趋势 - 2026-07-04

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于代理型用户体验（代理UX）和AI在设计中的应用。代理UX强调人机信任构建，而非仅界面和功能，提出了设计代理系统的7个原则，以增强上下文的双向流动和信任感。AI的应用正在改变设计工作流程，提升创意工作的适应性和团队协作。最值得关注的是代理UX设计原则和AI在设计中的深度整合。
