# 设计趋势 - 2026-05-09

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域主要关注AI在用户体验设计中的应用和优化。关键动态包括代理性用户体验设计指南的发布，强调理解用户目标的重要性；AI工作流程的自然交互和目标导向性；以及AI工作流程优化的实用技巧。最值得关注的是AI代理工作流设计模式的探讨，以及设计师角色转变对企业财务的影响。
