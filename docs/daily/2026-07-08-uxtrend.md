# 设计趋势 - 2026-07-08

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI与用户体验的融合。主要动态包括：1) 面向代理的用户体验设计，推动数字设备新体验；2) Cursor AI集成代码编辑器，革新交互方式；3) AI技术优化设计流程，提升效率；4) 探讨AI代理工作流设计模式；5) 设计代理系统需遵循7原则，增强信任与智能。最值得关注的是Cursor AI的集成应用和AI代理工作流设计模式的探讨。
