# 设计趋势 - 2026-06-02

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于人工智能与用户体验的融合。ChatGPT技术在界面设计中扮演重要角色，通过优化反馈提升用户体验。同时，设计师需考虑AI对数字产品设计的影响，尤其是在信息架构和个性化体验方面。最值得关注的是ChatGPT新图像生成器的应用，它能够助力设计师快速创建UI和视觉草图，标志着AI在设计领域的又一突破。
