# 设计趋势 - 2026-08-03

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于人工智能与用户体验的融合。主要动态包括代理UX设计原则、建立人机信任、AI工作流设计超越对话界面、以及用户体验2.0的代理体验设计。最值得关注的是人工智能时代下的用户体验2.0，它要求设计超越界面，融入逻辑、伦理和行为，以及Figma中AI工作流对创意流程的影响。
