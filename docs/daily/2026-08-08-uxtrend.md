# 设计趋势 - 2026-08-08

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于AI与用户体验的融合。最值得关注的是面向代理的用户体验设计，探讨了如何将AI代理融入数字设备体验设计中，实现人机无缝交互。此外，Figma社区提供的AI工作流程，通过图像、视频和创意生成，推动创意项目从概念到实现的效率。
