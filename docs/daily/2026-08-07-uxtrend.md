# 设计趋势 - 2026-08-07

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于人工智能时代的用户体验（UX）设计。主要动态包括面向代理的用户体验设计原则、建立人机信任的Agentic UX设计，以及将UX设计扩展至算法和机器。最值得关注的是Agentic UX设计，它强调在AI时代建立人机信任的重要性。此外，Figma社区提供的AI工作流，助力创意项目从概念到输出，也是今日设计领域的亮点。
