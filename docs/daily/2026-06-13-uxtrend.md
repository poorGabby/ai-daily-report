# 设计趋势 - 2026-06-13

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域资讯聚焦于AI在工作流设计中的应用。AI代理工作流设计模式成为焦点，强调其作为任务协调器的重要性。同时，AI技术正深度整合进设计流程，提升创意工作的适应性和团队协作。最值得关注的是AI在产品设计中的作用，通过数据分析帮助设计师理解用户需求，实现产品设计的个性化和效率提升。
