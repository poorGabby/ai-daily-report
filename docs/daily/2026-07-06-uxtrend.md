# 设计趋势 - 2026-07-06

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于代理UX设计和AI技术在设计工作流程中的应用。代理UX设计强调创造新型人机交互体验，而AI技术显著提升了设计流程的速度和协作性。最值得关注的是代理性用户体验对设计认知的改变，以及AI代理工作流设计模式的探讨。

---

**原文标题**: [UX design for agents](https://medium.com/microsoft-design/ux-design-for-agents-11336728b445)

**一句话摘要**: 探讨设计原则，以创造与数字设备的新类型用户体验。

**能解决什么问题**: 如何以人为中心，设计出与AI驱动的代理系统相融合的用户体验。

**产品应用**: 可以应用于实际产品，通过遵循设计原则，加速开发以人为本的代理系统。

**示例场景**: 使用代理系统协助团队协作和问题解决。
