# 技术发布 - 2026-05-12

> AI模型、API、开源项目、Agent、Infra

## 今日概览

今日技术发布领域主要聚焦于语言模型和API指南。General365和ReasonBENCH分别针对大型语言模型的推理性能和稳定性提出挑战，强调准确率提升和不稳定性量化的必要性。同时，Microsoft Agent Framework更新至1.3.0版本，微软代理框架1.0版本也带来了功能增强和结构改进。最值得关注的是Microsoft Agent Framework的更新，以及Gemini API的使用指南与示例发布，为开发者提供了实用的资源。
