# 技术发布 - 2026-06-12

> AI模型、API、开源项目、Agent、Infra

## 今日概览

今日技术发布领域主要动态集中在人工智能领域，特别是生成式AI和大型语言模型（LLM）的应用。Meta AI发布了两个重要的AI模型：Llama 3.1，一个开源且性能匹敌顶级闭源模型的405B参数模型；以及Llama 4系列，支持原生多模态和混合专家架构。此外，还提出了视觉推理基准（VRB）来评估多模态大型语言模型的能力，并探讨了基于扩散模型的视频生成技术进展。

最值得关注的是Meta AI的Llama 3.1模型，作为首个开源的高性能AI模型，它可能会推动AI技术的开放性和可访问性。同时，Llama 4系列模型的推出标志着多模态AI技术的新发展，为未来的AI应用开辟了新的可能性。
