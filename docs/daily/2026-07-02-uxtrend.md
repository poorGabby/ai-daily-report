# 设计趋势 - 2026-07-02

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于代理型用户体验（UX）设计和AI在设计工作流程中的应用。其中，代理型UX设计强调人机信任的协调，而非传统界面和功能，预示着设计认知的重大转变。同时，AI技术显著提升了设计效率，并助力创造更用户友好的AI产品。最值得关注的是代理型UX设计的理念革新以及AI技术在设计领域的深度融合。
