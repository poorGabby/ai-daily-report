# 设计趋势 - 2026-08-06

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于人工智能与用户体验的深度融合。主要动态包括：1) 面向代理的用户体验设计，探索新型设计原则；2) AI设计交互范式，重塑数字产品；3) 为人工智能设计交互，提升体验；4) 人工智能辅助界面设计趋势，关注新趋势；5) Agentic UX，建立人机信任关系。最值得关注的是AI设计交互范式和Agentic UX，它们预示着人机协作的新方向。

### 8. AI工作流设计规则：超越对话式代理

**原文标题**: [Medium](https://skooloflife.medium.com/the-biggest-mistake-in-ai-workflow-design-mimicking-human-process-instead-of-optimizing-function-628bfa37aa02)

**一句话摘要**: AI系统失败常因工作流设计错误，非模型问题。

**能解决什么问题**: 设计者常将AI误认为“某人”，而非“某物”，导致工作流设计不合理。

**产品应用**: 适用于任何AI产品，应将AI功能直接嵌入工作流程中。

**示例场景**: 在客户服务中，直接调用AI接口处理查询。
