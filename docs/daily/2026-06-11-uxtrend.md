# 设计趋势 - 2026-06-11

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势领域聚焦于AI在工作流程中的应用和用户体验。AI代理工作流设计模式被强调，旨在协调任务。最值得关注的是AI在提升用户信任和个性化产品设计方面的作用。AI通过透明度和可逆性原则增强信任，并利用数据分析助力设计师实现个性化设计。
