# 技术发布 - 2026-06-11

> AI模型、API、开源项目、Agent、Infra

## 今日概览

今日AI技术领域主要动态聚焦于生成性AI和大型语言模型（LLM）的新进展。Meta AI发布了两个重要的LLM模型：Llama 3.1和Llama 4，前者标志着开源AI模型的新里程碑，后者则支持原生多模态和长上下文理解。此外，Llama 3.2的发布预示着边缘AI和视觉技术的新变革，特别适用于移动和边缘设备。最值得关注的是Meta AI的Llama系列模型，它们在视频生成、理解和流媒体传输中的应用前景广阔，预示着AI技术在多模态理解和边缘计算领域的重要突破。
