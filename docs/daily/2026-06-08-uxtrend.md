# 设计趋势 - 2026-06-08

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势资讯聚焦于AI在工作流设计、创造方式、用户体验和界面设计中的应用。AI作为任务协调器，深度整合设计流程，提升团队协作和创造性工作。同时，AI交互模式和代理型用户体验设计成为新焦点，旨在建立人与AI的信任关系，预测用户未知需求。最值得关注的是AI在设计中的应用，它将改变我们的创造方式，以及ChatGPT对界面设计的影响，为独立开发者提供宝贵反馈。
