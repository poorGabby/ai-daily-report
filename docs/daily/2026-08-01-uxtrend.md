# 设计趋势 - 2026-08-01

> AI交互方式、Prompt UX、Agent UX、Workflow

## 今日概览

今日设计趋势聚焦于人工智能时代的用户体验（Agentic UX）设计，强调与数字代理交互的新原则和人机信任建立。同时，指出AI工作流程设计常因模仿人类而非优化功能而失败。最值得关注的是，91%的设计师认为AI提升了设计质量，标志着用户体验设计正从以人为中心转向包含算法和代理的混合体验。

### 3. AI工作流程设计误区：模仿人类而非优化功能

**原文标题**: [Medium](https://skooloflife.medium.com/the-biggest-mistake-in-ai-workflow-design-mimicking-human-process-instead-of-optimizing-function-628bfa37aa02)

**一句话摘要**: AI系统失败常因设计者将其视作“某人”而非“某物”。

**能解决什么问题**: AI工作流程设计中错误地模仿人类行为，导致效率低下。

**产品应用**: 适用于需要自动化和优化流程的产品，直接嵌入AI功能。

**示例场景**: 自动化客服系统无需模拟人类对话，直接处理查询。
